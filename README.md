# 阅见 · 考研英语精读站

本地运行的 React + TypeScript + Vite 阅读应用，配备 Express 服务端和兼容 Chat Completions 的第三方 AI 接口。

## 运行

需要 Node.js 22.12+ 或 24 LTS。

```powershell
npm install
npm run dev
```

打开 http://127.0.0.1:5173。开发服务为前端 5173、API 3001，仅监听本机。

生产运行：

```powershell
npm run build
npm start
```

打开 http://127.0.0.1:3001。`npm test` 运行订阅源解析、来源校验、每日去重、内容校验与 API 集成测试。

## 安卓手机本机运行

支持通过 Termux 在安卓手机上运行完整前端和 Node 后端，不要求电脑持续开机。Windows 电脑执行 `powershell -NoProfile -File deploy/android/package.ps1` 可生成包含源码和已构建页面的 `releases/readworld-android.zip`；手机安装运行依赖后访问 `http://127.0.0.1:3001`。

完整步骤见 [安卓部署说明](deploy/android/README.md)。部署包不会包含电脑的 API Key 和私人数据；AI 生成仍需联网，手机后台定时生成要求 Termux 服务持续运行。

## 学习功能

- 每日 3 篇，550–1000 英文词，按每分钟约 70 词估算精读用时。
- 英文每句后紧跟中文，支持仅英文、字号调整、点击核心词汇收藏。
- 每篇 8–12 个语境词汇与 3 道 A–D 选择题；作答齐全后提交，展示答案、中文解析和原文定位。
- 收藏、文章书架、生词自测、掌握标记、学习时长、连续学习与 7 日记录。
- 实际专注时长仅在阅读页可见且近两分钟有交互时累计；完成文章需点击完成或标记已读。
- 深色模式、键盘操作与手机布局。

## 连接 AI

点左下角「AI 与阅读设置」，选择 DeepSeek、通义千问、智谱或自定义服务，填写 Base URL、模型 ID 与 API Key，点击「保存并测试」。预置名称只是可编辑示例，具体模型权限、价格、参数支持以服务商为准。

- 自定义服务支持 OpenAI 兼容的 `/chat/completions` 接口，也可连接 Ollama 等本地兼容服务；本地无密钥服务可填写 `local`。
- Base URL 包含 `/v1` 等服务前缀，不必重复填写 `/chat/completions`。
- 不支持 `response_format` 的服务可关闭「JSON 输出模式」。
- 输出截断时提高最大输出 Token，或选择支持长输出的模型。
- Key 保存在本机 `data/library.json`，不会返回给浏览器。该目录已加入 `.gitignore`；文件是本地明文，请勿分享或上传。也可在启动前设置 `AI_API_KEY` 环境变量，避免写入文件。
- 环境变量不自动读取 `.env` 文件。PowerShell 示例：`$env:AI_API_KEY = '你的密钥'`，然后启动应用。

## 文章来源与内容标注

来源限定为《经济学人》《卫报》《基督教科学箴言报》《自然》《科学美国人》《大西洋月刊》《纽约时报》。后端从固定官方 RSS 地址读取最近 14 天的标题、摘要与原始链接，拒绝其他域名、未来日期、过期及重复内容。界面显示每个源的实际连接状态，不把连接失败伪装成最新内容。

点击「AI 自动获取今日文章」后，后台依次执行：

1. 读取指定媒体最近 14 天的官方公开 RSS，核验域名和日期。
2. 调用你已接入的大模型，从真实候选中选择适合考研精读的三篇，并给出中文选文理由。模型不能凭记忆编造链接；同一链接 14 天内不重复选用。
3. 自动访问所选文章的公开网页，用 Readability 提取公开正文，逐次检查跳转域名，不运行网页脚本。
4. 将实际读到的资料交给同一个模型，以原创结构和表达制作学习文章、逐句翻译、核心词汇和三道题，逐篇保存到今日精读。

这是**有真实来源参考的 AI 学习创作，不是媒体原文转载**。若页面明确标注为订阅内容、正文过短或网络不可达，会退回公开标题和简述，并明确显示「未获取原文」及原因，绝不声称已经读过正文。公开正文只用于当次模型请求，不会保存或返回给浏览器。题材适合考研训练，但词汇不宣称经过官方考研词表认证。AI 内容可能存在事实、翻译或出题错误，请核对来源。

获取、模型择文、读取正文、生成四个阶段均在页面实时显示。任务创建后立即返回，重复点击会复用当前任务。内容校验失败时最多自动修正一次，仍不合格则显示错误，不覆盖已有文章。

网络请求优先使用 `HTTPS_PROXY` / `HTTP_PROXY`；Windows 上未设置环境变量时会读取当前用户已启用的系统 HTTP(S) 代理。不会修改系统代理设置。本地模型、localhost 与 `NO_PROXY` 指定地址始终绕过代理。不自动执行 PAC 脚本，也不关闭 TLS 证书验证。

要研读指定媒体的真实全文，请在「文章书架 → 导入文章」中粘贴你有权使用的正文和对应官方链接。英文正文发送给已配置的 AI 服务，用于逐句翻译和出题；它不会自动提取付费全文。

首次打开有 3 篇完整的原创教学示例，可在没有密钥或网络时体验。示例明确标为「原创示例」，没有伪造媒体发布日期，媒体标签仅表示选题方向。

## 自动计划与数据

设置中开启每天自动生成，选择北京时间的整点。**本地 Node 服务必须保持运行**；如果错过时刻，服务在当天该时刻后启动时补做。不是云端定时任务，不会在电脑关机时执行。

同一天最多自动准备 3 篇，已成功生成的文章会逐篇保存。自动任务每天只尝试一次，失败可手动重试，只补齐当天未完成的数量。模型调用会消耗所配置服务的额度。

- 后端 `data/library.json` 保存设置、AI 文章和每日计划；`READWORLD_DATA_DIR` 可指定其他目录。
- 浏览器 `localStorage` 保存学习记录、生词、收藏与主题，按浏览器隔离；清除站点数据会删除这些记录。
- 服务仅供个人本机使用。没有多用户账户或互联网部署认证，默认不向局域网或公网开放。
- `PORT` 可调整生产端口；开发时如修改 API 端口，也要同步修改 `vite.config.ts` 的代理目标。
